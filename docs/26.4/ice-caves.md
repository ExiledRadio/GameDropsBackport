  - humidity = span(-1.0, 0.7)

### Ore family (UNDERGROUND_ORES)
There are 21 placed `ice_cave_ore_*` files (the brief said 22; the files list and the biome both have exactly 21) and 16 configured `ice_cave_ore_*` features. `ice_cave_ore_diamond_small` is used by placed `ice_cave_ore_diamond`.

- [ ] Every placed ice_cave_ore_* has a placement list **identical** to its vanilla `ore_*` counterpart. This was checked programmatically against `placed_feature/ore_*.json`. Only the feature reference changes.

**"Hosted" ore** (`data/worldgen/features/OreFeatures.java:71-73`, `hostedOre`) is `type: minecraft:sequence` (`world/level/levelgen/feature/SequenceFeature.java:33-43`). It places each inner feature at the same origin with the shared random, and **stops at the first one that returns false**.
- Inner 1, the host blob: `ore` size **20**, discard 0.0. It turns cave ice and calcite back into stone or deepslate so the ore is wrapped in rock. Targets come from `iceCavesOreTargetList(STONE, DEEPSLATE)` (`OreFeatures.java:88-94`, `75-81`), first match wins:
  - #stone_ore_replaceables → stone
  - #deepslate_ore_replaceables → deepslate
  - (height_match y 4..2031) AND (#height_specific_ore_replaceables OR #ice_cave_ore_replaceables) → stone
  - (#height_specific_ore_replaceables OR #ice_cave_ore_replaceables) → deepslate. That is y < 4, since the previous entry catches the rest.
- Inner 2: the normal vanilla ore feature, with vanilla targets (stone ore / deepslate ore / tuff y>=4 → stone ore / tuff → deepslate ore) and vanilla size and discard.
